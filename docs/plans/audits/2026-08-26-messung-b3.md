## Die Prüfung

Neuer CI-Job `dead-code` („Dead code (knip)") in `test.yml`, aufgenommen in
`CI Summary`. Er läuft `npm run knip` im Frontend und ist rot bei einem
einzigen Befund. `knip.json` nennt die Ausnahmen mit Grund: vier
ESLint-Pakete und das `eslint`-Binary kommen aus dem Wurzel-`package.json`,
`tailwindcss`/`tw-animate-css` werden aus CSS geladen, `@arasul/shared-schemas`
und `@testing-library/dom` sind Peer-Abhängigkeiten. `toter-code.sh` im
`guards`-Job bleibt: er prüft auch das Backend.
